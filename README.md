# CRUD Kontak — Svelte + Supabase

## Setup

1. Buat project di Supabase, lalu salin Project URL dan publishable key ke `.env.local` mengikuti `.env.example`.
2. Jalankan SQL ini di **Supabase → SQL Editor**:

```sql
create table public.contacts (
  id bigint generated by default as identity primary key,
  nama text not null,
  nomor_telepon text not null
);

alter table public.contacts enable row level security;
grant select, insert, update, delete on public.contacts to anon, authenticated;
grant usage, select on sequence public.contacts_id_seq to anon, authenticated;

create policy "Demo contact CRUD"
on public.contacts for all to anon, authenticated
using (true) with check (true);
```

3. Jalankan `bun install` lalu `bun run dev`, dan buka alamat yang ditampilkan.

Kebijakan demo mengizinkan siapa saja mengakses data kontak. Jangan gunakan untuk data pribadi atau aplikasi publik.
